# Defensa de tesis: GENDocs V3

Diapositivas de la defensa del trabajo de titulación *Sistema web modular para la gestión documental académico-administrativa de la FISEI-UTA y su incidencia en la mantenibilidad (ISO/IEC 25010)*, Universidad Técnica de Ambato.

- Paleta granate: `deck.html`
- Paleta azul: `deck-azul.html`

Se presenta desde el navegador: tecla P para empezar, flechas para avanzar, clic sobre una captura o un clip para ampliarlo.

La tipografía Crimson Pro se distribuye bajo la licencia SIL Open Font License (`OFL-CrimsonPro.txt`). Los logos de tecnologías provienen de Simple Icons.
